# {frontmatter.title}

ApplePad 组件用于模拟 iPad 设备的外观，包含状态栏、时间显示和设备边框。
适用于创建平板应用界面原型或展示平板端设计效果。

## 案例

<ApplePadPackage.Basic />

## Props

### backgroundColor

内容区域背景色，等同于为其内部的 Container 设置背景色。支持预设的语义化颜色和透明度变体。

<ApplePadPackage.BackgroundColor />

### height

窗口高度，支持多种预定义尺寸选项。

<ApplePadPackage.Height />

### showFrame

是否显示 iPad 边框，设置为 false 时只显示内容区域。

<ApplePadPackage.ShowFrame />

### title

窗口标题，显示在状态栏中的标题文本。

<ApplePadPackage.Title />

### withShadow

是否显示阴影效果，为 iPad 窗口添加立体感。

<ApplePadPackage.WithShadow />

## Slots

### default

主要内容区域，用于放置应用界面内容。
